# MySQL 连接池统一使用 Druid

用户已要求使用 Druid，并授权仅修改必要的依赖声明，不运行 Maven。

- 范围：用户、商品、订单、支付、库存、文件、评论七个 MySQL 服务。
- 官方 Boot 3 starter 1.2.27，根项目统一管理版本；只在需要 JDBC 的服务声明，排除其 JDBC/MyBatis 路径的 HikariCP。
- 明确 datasource.type，并使用 spring.datasource.druid 标准属性。默认初始化1个、最小空闲1个，最大10个（评论服务5个），获取连接最多等待3秒；空闲检测 SELECT 1。
- Druid 监控 Servlet 和 Web Filter 关闭，不额外发布监控入口；Mongo 驱动连接池保持不变。
- 检查：XML依赖契约、七份YAML结构及属性解析、diff检查。不进行依赖解析、Java编译或真实连接池启动验证。
- 不修改数据库结构，不启动/停止服务，不提交或推送。

执行结果：七个服务的声明和配置已修改；XML静态契约检查通过，七份YAML结构及关键参数解析通过，diff检查通过（仅现有IDE文件换行提示）。未运行Maven、构建、Java单测或重启，运行时切换待新配置启动。
