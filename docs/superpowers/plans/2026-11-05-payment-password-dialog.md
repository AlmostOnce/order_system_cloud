# 移动端支付密码独立弹层

用户要求支付等临时密码输入不在正文展开，避免小屏滚动和键盘遮挡。订单支付、余额充值统一使用uni-app x dialogPage；设置/修改支付密码保留独立页面。

- 新增只在内存保留的单次密码请求与独立弹层页面；URL仅含请求编号，不含密码。
- 弹层显示金额，主动聚焦，按键盘高度调整自身可用区域；取消/返回/销毁清空密码并结束请求。
- 订单与充值先校验业务状态，再打开弹层。确认后复用原有支付/充值接口、幂等与结果待确认逻辑；避免重复弹层或提交。
- 检查：真实setup交互回归、取消与关闭竞态、密码清理、原生模板约束、HBuilder V真机编译日志。
- 不运行Maven，不变更后端接口。
