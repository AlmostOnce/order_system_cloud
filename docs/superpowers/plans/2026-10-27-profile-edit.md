# 个人资料编辑实施计划

用户确认允许编辑绑定邮箱，换绑后使用新邮箱匹配密码登录。复用现有个人资料页与头像预览，不增加手机号或其他身份字段。

1. 增加白名单请求DTO及本人PUT接口，JWT定位用户；业务层校验昵称、邮箱、换绑登录密码和唯一性，用本地事务及用户行锁更新指定列，复用资料返回对象。
2. 在资料卡内提供编辑、保存和取消，使用共享账户表单样式；保存与刷新互斥，失败保留草稿，每次保存结束及离开页面清空密码。
3. 增加后端测试源码（不运行Maven）和真实Vue setup前端回归检查，覆盖换绑确认、验证失败、重复提交、取消和密码清理；执行现有前端检查与HBuilderX Web构建。
4. 更新接口、交互规范与验证边界，不重启服务、不执行数据库迁移、不提交或推送。
