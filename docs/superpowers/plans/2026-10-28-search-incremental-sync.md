# 菜品搜索索引增量同步实施计划

**目标：** 菜品变更只同步单个菜品，关联信息按受影响窗口刷新，全量重建安全切换并定期对账。

**架构：** 商品服务在本地事务中写入兼容旧窗口事件的 outbox；搜索服务读取最新商品快照，使用分布式锁处理乱序和重建并发。全量重建先写独立索引，成功后原子切换别名。对账以商品服务为事实源，修复缺失和过期文档。

**约束：** 保留已有工作区改动和旧消息兼容；数据库变更先提供迁移脚本；不运行 Maven、构建或重启。

1. 增加向后兼容的 outbox 菜品标识、单菜品快照接口和按菜品登记事件，保留窗口事件。
2. 消费时按菜品写入或删除单个搜索文档，窗口事件继续刷新关联文档。
3. 建立搜索别名与影子索引重建，控制重建期间消息并发，并保留原索引以便恢复。
4. 增加定期对账和启动恢复，处理缺失、失效及人工改库的数据。
5. 核对迁移、配置、旧消息兼容及接口行为，记录无法执行的运行验证。
