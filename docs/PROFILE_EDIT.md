# 本人资料编辑

PUT `/api/users/me/profile`，需登录，用户归属只取已认证的 JWT 主体，不接收用户 ID、用户号、身份、余额等可写字段。

请求：`{username,email,loginPassword}`。昵称去空格后长度2至64；邮箱去首尾空格并小写，最大254字符。未绑定邮箱的历史用户可保持空值只改昵称，已有绑定不能清空。邮箱变化时校验当前登录密码，成功后新邮箱替换旧邮箱参与现有登录查询；用户号、UUID、登录密码不变。本次未增加邮件验证码服务，也不表示已验证邮箱所有权。

后端在同一事务内锁住本人用户行，只更新昵称、邮箱、版本及更新时间，避免覆盖余额、头像或权限；昵称邮箱唯一约束兜底并发冲突。返回现有 UserProfileVO，密码不回传，DTO 的 toString 隐去凭据。

前端复用个人资料页、账户共享样式和网络层，提供编辑、保存、取消、错误恢复和密码清理。Java回归测试源码包含密码校验、冲突、账号不可用及身份字段保留；按项目约束未运行 Maven，未进行后端构建或启动验证。

前端验证：12项检查（含新增资料编辑）全部通过；HBuilderX 5.26 Web构建完成，日志无警告。使用隔离API测试数据在浏览器验证编辑入口、邮箱变更展开密码、缺少密码拦截、保存更新和390px手机布局；未修改真实用户数据。此验证不替代后端Java构建或真实接口联调。
